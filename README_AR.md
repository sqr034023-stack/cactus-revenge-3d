# انتقام الصبار — لعبة ثلاثية الأبعاد ببايثون

أُعيد بناء اللعبة بمحرك **Panda3D**، وهو محرك ثلاثي الأبعاد يعمل ببايثون. المشهد يحتوي على صبار وديناصورات ومجسمات صحراوية وإضاءة ومنظور كاميرا ثلاثي الأبعاد. تشمل النسخة القفز، النقاط، الأرقام القياسية، وشحنة درع حماية مؤقتة بدلاً من إطلاق المقذوفات.

## تشغيل نسخة الكمبيوتر

```bash
python -m pip install panda3d
python main.py
```

## بناء Android App Bundle (AAB)

Panda3D يدعم إنشاء AAB مباشرة عبر `build_apps`، لكن بناء Android يحتاج بيئة Linux أو macOS، وAndroid SDK/NDK، وعجلات Panda3D المخصصة لأندرويد. لا تكفي عجلة Panda3D العادية الخاصة بالكمبيوتر.

1. ثبّت Python 3.8 أو أحدث وPanda3D 1.11 أو إصداراً أحدث يدعم Android.
2. جهّز Android SDK/NDK حسب دليل Panda3D الرسمي.
3. جهّز عجلات Panda3D لأندرويد للمعماريتين `arm64-v8a` و`armeabi-v7a`، وضعها في مجلد `android-wheels`.
4. ملف `requirements.txt` مضبوط لاستخدام المجلد المحلي `android-wheels`؛ ضع داخله ملفات العجلات الصحيحة ثم نفّذ:

```bash
python -m pip install panda3d
python setup.py bdist_apps
```

عند اكتمال الإعداد والبناء بنجاح، يُنشأ ملف `.aab` داخل `dist/`.

**الوثائق الرسمية:** [Panda3D — Building for Android](https://docs.panda3d.org/1.11/python/distribution/building-for-android)

## حالة الملفات

- هذا التسليم يحتوي على مصدر اللعبة وإعدادات البناء.
- **لم يُنشأ ملف AAB جاهز في هذه الجلسة**؛ بيئة التنفيذ الحالية لا تحتوي على Android SDK/NDK ولا عجلات Panda3D الخاصة بأندرويد.
- يجب اختبار اللمس والأداء على هاتف Android فعلي قبل النشر.
- لا ترفع التطبيق إلى المتجر قبل اختباره وتوقيع AAB بمفتاح نشر خاص بك. احتفظ بالمفتاح وكلمة مروره سريين.
